fixed-public-media retains its existing size-only fixture, preparation and budgets.

real_commons_file example; no arbitrary query, URL, command or executable input.
Admission requires attempt1, exact source/checkout, successful two-OS deterministic
contracts and this run's readiness-native matrix. The retained choice additionally
requires six named production discovery verifier tests in a second native matrix.
Both use the existing collector/codec; old default signatures and boundary remain.
Independent native contracts use their own binary/generation, never pretend that
Tor journey stages are independent probes. This is not a performance comparison.

Profile mismatch, absent/stale/foreign/wrong-boundary/zero-executed prerequisite,
missing/corrupt retained output and failed cleanup cannot mint retained-file success.
Before launch the adapter freezes both prerequisite hashes, profile/source and
binary/config/evaluator identities. It invokes the existing journey ONCE in owned
HOME/temp and a process group, reuses the existing file readback, and rechecks at
closeout. The fixed 330-second outer cap applies to the whole dependent journey;
readiness/search and retrieval are not timed as comparable independent experiments.
Only JSON/raw bounded logs and retained-file/receipt.json + selected.webm are uploaded,
never the Tor cache/state or owned HOME/temp. A partial uploaded file is not acceptance.
