# Support PULQVA

Help make private file discovery usable by people who do not want to configure
a collection of command-line tools.

[Support the maintainer on GitHub Sponsors](https://github.com/sponsors/yasha1971-coder)

This is the maintainer's existing, shared sponsorship profile. It currently describes
ACEAPEX and GLYPH as well; a donation is not automatically earmarked for PULQVA.
No new payment account, project-specific tier or delivery contract is created here.

## Priorities worth funding

| Priority | Evidence of completion |
| --- | --- |
| Reproducible request-to-file journey | An independently runnable package, real candidates and a saved file |
| Zero-configuration packaging | Clean-machine Windows/Linux startup and documented supported versions |
| Privacy and supply-chain review | A defined review scope, public findings and tracked remediation |

These are funding priorities, not fixed-price offers. Budgets and delivery dates need
a scoped proposal. Sponsorship does not buy access to user queries, influence over
search results, or an exception to the privacy contract.

Engineering progress is public in commits, pull requests, CI results and NEXT.md.
A funded milestone should identify its scope, budget, acceptance evidence and status.
No independent audit or successful pilot is claimed yet.

## Help without donating

Review code and the threat model, report reproducible problems, or propose a pilot
use case through [Issues](https://github.com/yasha1971-coder/PULQVA/issues).
Do not post private queries, credentials or sensitive documents in public issues.
