# PULQVA v0.1.0-alpha.1 — инженерный прототип

Это кандидат прототипа, НЕ готовый приватный релиз PULQVA v1.

Распакуйте весь пакет в отдельную доверенную папку. На Windows запустите PULQVA.exe; на Linux — PULQVA. Откроется локальная страница в вашем браузере. Введите, например, `countdown`, получите реальные варианты Wikimedia Commons, нажмите «Получить файл». Файл сохраняется в `Downloads/PULQVA/file-…/selected.webm`. Завершайте приложение кнопкой «Завершить» в странице.

Реализуемый узкий сценарий: текстовый поиск Commons, до 10 небольших WebM-видео размером до 8 МиБ, ручной выбор, загрузка через встроенный Tor, проверка размера/SHA-1 и SHA-256 сохранённых байтов. Используются существующие Rust-компоненты PULQVA, а не новый скачивающий движок. SHA-1 сравнивается с метаданными провайдера, SHA-256 обозначает локальные байты: это не подпись издателя.

Сборочная среда имеет сетевой доступ для получения зависимостей. В самом прототипе интерфейс обращается только к локальному адресу; внешний поиск выполняется существующим Tor HTTPS-транспортом, загрузка — существующим Tor-gated yt-dlp. Нет намеренного прямого сетевого fallback. URL локального интерфейса содержит случайный одноразовый секрет; запросы пользователя не пишутся в URL, лог или постоянную квитанцию.

## Ограничения, которые нельзя скрывать

* ИИ-интерпретация, Autopilot, другие провайдеры и интеграция с основным интерфейсом Tauri НЕ подключены. Это не изменение цели Kernel.
* Используется обычный браузер для локальной страницы, не отдельная защищённая браузерная среда. Его расширения, история и фоновые обращения ОС не контролируются. Не вводите чувствительные запросы.
* Полный пользовательский сетевой E2E, измерение утечек, принудительное завершение дерева процессов, гонки файловой системы, лицензии полного комплекта и запуск на чистом компьютере ещё требуют отдельной приёмки. Не публикуйте как проверенный приватный продукт.
* Windows: x86_64 и установленный браузер. Linux: сборка для Ubuntu 24.04 x86_64, графическая сессия, браузер и xdg-open. Это не универсальный Linux-пакет.
* Tor использует локальный порт 19050. Запускайте только одну копию. При конфликте или отказе Tor операция останавливается. Во время начальной проверки Tor завершение может быть отложено до её тайм-аута.
* Закрытие вкладки не равно остановке процесса; используйте кнопку «Завершить». Удаление временных данных предусмотрено на штатных ветках завершения, но не гарантируется при аварийном убийстве процесса или отключении питания.
* Работа сайтов через Tor, доступность подходящих файлов и скорость не гарантированы. Большие файлы, аудио, плейлисты, авторизованные сайты и YouTube не поддерживаются этим прототипом.

`prototype-manifest.json` содержит контрольные суммы содержимого пакета и точный коммит. Внешняя `.sha256` относится к ZIP. Совпадение хешей не доказывает подлинность подписанта и не заменяет доверенную доставку.

## Разработка

`cargo test --locked -p pulqva-discovery --bin pulqva-prototype`

`cargo build --locked --release -p pulqva-discovery --bin pulqva-prototype`

`node --test apps/pulqva-prototype/test_ui.mjs`

`python apps/pulqva-prototype/package.py --self-test`

Контракт PULQVA v1 остаётся прежним: автономное приложение Windows/Linux, понимание естественного запроса без аккаунта/API-ключа, реальные варианты, ручной выбор/Autopilot и получение файла с проверяемой конфиденциальностью.
