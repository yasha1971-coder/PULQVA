# ADR-0005 — Apache-2.0 for original PULQVA work

Status: Proposed in sponsorship/documentation PR; not yet merged
Date: 2026-09-25

## Decision

Use Apache-2.0 for original PULQVA code and documentation. Preserve separate licenses
and notices for all third-party components. No kernel or runtime change.

## Rationale and trade-offs

A standard permissive license supports reuse and commercial adoption, includes an
express contributor patent grant, and requires preservation of applicable notices.
It allows proprietary derivatives; it does not require downstream improvements to
be published. It does not establish copyright ownership or clear third-party rights.

## Release condition

Complete the exact binary licensing/source inventory described in THIRD_PARTY.md
before distributing packages. Sponsorship does not alter these terms.
