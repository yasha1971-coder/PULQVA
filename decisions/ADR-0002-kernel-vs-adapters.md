# ADR-0002 — Freeze outcomes, not implementation tools
Status: Accepted  
Date: 2026-09-20

## Decision
The v1 kernel freezes user and privacy outcomes, not specific frameworks or providers.

Tauri, Vite/Rolldown, Farm, React, Duck.ai, yt-dlp, Arti, ranking algorithms and future alternatives are implementation/adaptor decisions unless explicitly promoted into a later kernel.

## Reason
This preserves the product identity for years while allowing the technical stack to improve.
